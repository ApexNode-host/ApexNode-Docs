## Git authorship and commit subjects (required)

Forward-only policy for new Docs commits and PRs. Do not rewrite existing history.

- Author and committer: `Yovez <yovez11@gmail.com>`
- Open and push PRs as the board GitHub identity (`Yovez`), not a bot account
- Never add `Co-authored-by: Cursor` (or equivalent Cursor / Paperclip co-author trailers)
- Commit subjects and PR titles: plain English only
- Never prefix subjects or PR titles with issue ids (`APE-12:`, `APE-N`, etc.)
- Issue id may appear in the PR body only, e.g. `Paperclip: APE-12`
- Branch names may include issue ids; titles and commit subjects must not
