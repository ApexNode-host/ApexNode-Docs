# Dedicated Server Guides

These guides cover **dedicated (bare metal) servers** from ApexNode. That is a different product from game server hosting on the [game panel](https://panel.apexnode.host).

You order and pay in the [billing portal](https://dash.apexnode.host). When the machine is ready, you manage it from the [Cloud portal](https://cloud.apexnode.host) (SSH and root access), not the game panel.

### Guides in this section

- [Ordering a dedicated server](ordering) - marketplace vs build-your-own, what to pick
- [After you order](after-order) - emails, setup times, when you get login details
- [First login and access](access) - Cloud portal, SSH, passwords
- [Control panels and licenses](control-panels) - no panel by default, cPanel, CloudLinux
- [IP addresses](ip-addresses) - how many usable IPs you are buying
